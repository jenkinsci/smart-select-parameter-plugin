A JSON object that maps parent parameter values to option arrays. Use this together with Parent parameters when you do not have a REST URL — the options come from this static map instead.

Single parent: the key is the parent's selected value.

{
  "dev":  ["service-a", "service-b"],
  "prod": ["service-a", "service-c"]
}

Rich labels are also supported (same format as the Display labels and values field):

{
  "dev":  [{"value": "svc-a", "label": "Service A"}, {"value": "svc-b", "label": "Service B"}],
  "prod": [{"value": "svc-a", "label": "Service A"}, {"value": "svc-c", "label": "Service C"}]
}

Multiple parents (dependsOn: 'ENV,REGION'): the key is the parent values joined by a comma in the same order as Parent parameters.

{
  "dev,us-east":  ["cluster-dev-1"],
  "prod,us-east": ["cluster-prod-1", "cluster-prod-2"]
}

In a Jenkinsfile you can pass a Groovy map directly:

smartSelect(
    name: 'SERVICE',
    mode: 'SINGLE',
    dependsOn: 'ENV',
    dependentOptions: [
        dev:  ['service-a', 'service-b'],
        prod: ['service-a', 'service-c']
    ]
)

If the parent's current value does not match any key the dropdown shows no options. Leave this field empty to show the same static choices regardless of the parent value.
